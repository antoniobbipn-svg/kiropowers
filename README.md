# Kiro Powers

Repositorio de [Kiro Powers](https://kiro.dev/docs/powers/) reutilizables. Cada subcarpeta es un Power independiente, instalable en Kiro vía **Add power from GitHub** (apuntando a la subcarpeta) o **Add power from Local Path**.

## Powers disponibles

| Power | Carpeta | Descripción |
|---|---|---|
| Canales Digitales AMX · Estándar de Trabajo | [`canales-digitales-amx/`](./canales-digitales-amx) | Estándar de trabajo reutilizable: reglas (Git, modalidades, QA, acceso a BD, frontend), steering semilla de arquitectura, sistema de diseño Claro Atlas y MCP MySQL semilla con placeholders. |

## Instalación

1. Abre Kiro → panel **Powers**.
2. **Add power from GitHub** y apunta a la subcarpeta del Power deseado, o clona el repo y usa **Add power from Local Path**.
3. Sigue el onboarding del `POWER.md` de cada Power.
